# taller-arquitectura — EventFlow

Repositorio del Taller de Arquitectura de Software (UMB).

- `index.html`: monolito de ejemplo (con malos olores intencionales para SonarCloud).
- `.github/workflows/ci.yml`: pipeline CI (build -> test -> despliegue simulado).
- `main.tf`: infraestructura como código (Terraform, Google Cloud). Solo `init` y `plan`.
- `openapi.yaml`: API mínima de Eventos/Pedidos para Swagger Hub.
