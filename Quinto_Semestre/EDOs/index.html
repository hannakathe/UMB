01

¿Qué es una EDO y cómo se resuelve?

La idea central

Una ecuación diferencial ordinaria (EDO) es una ecuación donde la incógnita no es un número, sino una función, y la ecuación involucra esa función y sus derivadas.

Ejemplo cotidiano: si sabes que algo crece a una velocidad proporcional a su tamaño, eso es una EDO. No sabes cuánto hay en cada momento (eso es lo que quieres encontrar), pero sí sabes cómo cambia.

Forma general de una EDO F(x, y, y', y'', ..., y⁽ⁿ⁾) = 0

Donde y es la función que buscas, y los primos son sus derivadas.

Métodos principales

  • Separación de variables — separas todo lo de y a un lado y todo lo de x al otro, e integras.
  • Factor integrante — para EDOs lineales de primer orden.
  • Ecuaciones exactas — cuando la EDO es derivada de una función potencial.
  • Sustitución homogénea — cambias variable con y = vx.
  • Ecuación característica — para EDOs de segundo orden con coeficientes constantes.
La solución de una EDO no es un número, es una función (o familia de funciones). La constante C que siempre aparece representa la familia completa.
FÁCIL Separación de variables básica ▼
Resolver: dy/dx = 2x
Paso 1 — Identificar el método

La ecuación ya está separada: el lado derecho solo tiene x. Simplemente integramos ambos lados.

Paso 2 — Separar e integrar
dy = 2x dx ∫ dy = ∫ 2x dx y = x² + C
Paso 3 — Verificar

Derivamos la solución: si y = x² + C, entonces dy/dx = 2x ✓

Solución general
y = x² + C
DIFÍCIL Separación con condición inicial ▼
Resolver: dy/dx = (x·y²)/(1+x²), con y(0) = 1
Paso 1 — Separar variables

Movemos y al lado izquierdo y x al derecho.

dy/y² = x dx / (1+x²) y⁻² dy = x/(1+x²) dx
Paso 2 — Integrar ambos lados

Izquierda: integral de y⁻² = -y⁻¹

Derecha: usamos sustitución u = 1+x², du = 2x dx

∫ y⁻² dy = ∫ x/(1+x²) dx -1/y = (1/2)ln|1+x²| + C
Paso 3 — Aplicar condición inicial y(0)=1
-1/1 = (1/2)ln(1+0) + C -1 = (1/2)(0) + C → C = -1
Paso 4 — Despejar y
-1/y = (1/2)ln(1+x²) - 1 1/y = 1 - (1/2)ln(1+x²) y = 1 / [1 - (1/2)ln(1+x²)]
Solución particular
y = 2 / [2 - ln(1+x²)]
02

Orden y Grado de una EDO

Orden

El orden de una EDO es el número de la derivada más alta que aparece.

  • y' + 3y = 0 → orden 1 (solo aparece y')
  • y'' - 5y' + 6y = 0 → orden 2 (la más alta es y'')
  • y''' + y = x → orden 3

Grado

El grado es el exponente al que está elevada esa derivada de mayor orden, después de despejarla y eliminar raíces.

  • (y'')² + y = x → grado 2 (y'' está al cuadrado)
  • y''' + y' = 0 → grado 1 (y''' está a la 1)
  • √(y'') = x → hay que elevar al cuadrado → y'' = x² → grado 1
Si la derivada está dentro de una función como sin(y'') o eʸ'', el grado no está definido (no se puede aislar polinomialmente).

Lineal vs No lineal

Una EDO es lineal si y y todas sus derivadas aparecen solo a la 1era potencia, sin multiplicarse entre sí, y sin estar dentro de funciones.

  • y'' + 3y' - 2y = cos(x) → lineal
  • y·y' = x → no lineal (y multiplicada por y')
  • (y')² + y = 0 → no lineal (y' al cuadrado)
FÁCIL Clasificar una EDO simple ▼
Clasificar: 3y'' + xy' - y = sin(x)
Orden

La derivada más alta es y'' → orden 2

Grado

y'' aparece a la potencia 1, sin raíces → grado 1

¿Lineal?

y'', y', y aparecen solo a la 1ra potencia, sin multiplicarse entre sí. El sin(x) está del lado derecho (no afecta la linealidad). → Sí es lineal

Clasificación
Orden 2 · Grado 1 · Lineal
DIFÍCIL Clasificar una EDO con raíz ▼
Clasificar: √(1 + (y'')³) = x·y
Paso 1 — Eliminar la raíz

Elevamos ambos lados al cuadrado para poder identificar el grado.

1 + (y'')³ = x²y²
Orden

La derivada más alta es y'' → orden 2

Grado

Después de elevar al cuadrado, y'' está elevada a la 3ra potencia → grado 3

¿Lineal?

y'' está al cubo, y y están multiplicadas → No es lineal

Clasificación
Orden 2 · Grado 3 · No lineal
03

EDOs Lineales de Primer Orden

Forma estándar

Una EDO lineal de primer orden siempre se puede escribir como:

y' + P(x)·y = Q(x)

Donde P(x) y Q(x) son funciones conocidas. El truco para resolver esto se llama factor integrante.

¿Qué es el factor integrante?

Es una función μ(x) que, cuando multiplicas toda la ecuación por ella, el lado izquierdo se convierte en la derivada de un producto. Eso te permite integrar directamente.

Factor integrante μ(x) = e^(∫P(x) dx)

Algoritmo completo

  1. Pon la ecuación en forma estándar: y' + P(x)y = Q(x)
  2. Calcula μ = e^(∫P dx)
  3. Multiplica toda la ecuación por μ
  4. El lado izquierdo se convierte en d/dx[μy]
  5. Integra ambos lados: μy = ∫μQ dx + C
  6. Despeja y
El lado izquierdo siempre se convierte en (μy)' = μQ. Esto es lo mágico del factor integrante — no tienes que verificarlo, siempre funciona.
FÁCIL Factor integrante con P constante ▼
Resolver: y' + 2y = 4
Paso 1 — Identificar P y Q
P(x) = 2, Q(x) = 4
Paso 2 — Factor integrante
μ = e^(∫2 dx) = e^(2x)
Paso 3 — Multiplicar por μ
e^(2x) y' + 2e^(2x) y = 4e^(2x) (e^(2x) y)' = 4e^(2x)
Paso 4 — Integrar
e^(2x) y = ∫4e^(2x) dx = 2e^(2x) + C
Paso 5 — Despejar y
y = 2 + Ce^(-2x)
Solución general
y = 2 + Ce^(-2x)
DIFÍCIL Factor integrante con P(x) variable ▼
Resolver: xy' - y = x²·e^x, con y(1) = 0
Paso 1 — Forma estándar (dividir todo por x)
y' - (1/x)y = x·e^x

P(x) = -1/x, Q(x) = xe^x

Paso 2 — Factor integrante
μ = e^(∫-1/x dx) = e^(-ln|x|) = 1/x
Paso 3 — Multiplicar por 1/x
(1/x)y' - (1/x²)y = e^x (y/x)' = e^x
Paso 4 — Integrar
y/x = ∫e^x dx = e^x + C y = xe^x + Cx
Paso 5 — Condición inicial y(1)=0
0 = 1·e¹ + C·1 → C = -e
Solución particular
y = xe^x - ex = x(e^x - e)

Crecimiento Poblacional I — Modelo Exponencial

La idea

Si una población crece a una tasa proporcional a su tamaño actual (más gente → más nacimientos), la EDO es:

dP/dt = k·P

Donde k es la tasa de crecimiento (positivo = crece, negativo = decrece). Se resuelve por separación de variables.

Solución

P(t) = P₀ · e^(kt)

P₀ es la población inicial (en t=0), k se determina con otro dato del problema.

También modela: enfriamiento/calentamiento de objetos (Ley de Newton), desintegración radiactiva, crecimiento de bacterias, interés compuesto continuo.

Cómo encontrar k

Si te dan la población en dos momentos, usas el segundo para encontrar k:

P(t₁) = valor₁ → P₀·e^(k·t₁) = valor₁ → k = ln(valor₁/P₀)/t₁
FÁCIL · APLICADO Bacterias duplicándose ▼
Una colonia de bacterias tiene 500 al inicio. Se duplica cada 3 horas. ¿Cuántas hay a las 9 horas?
Paso 1 — Plantear la EDO
dP/dt = kP, P(0) = 500
Paso 2 — Encontrar k (se duplica en t=3)
1000 = 500·e^(3k) 2 = e^(3k) → k = ln(2)/3 ≈ 0.231
Paso 3 — Evaluar en t=9
P(9) = 500·e^(0.231·9) = 500·e^(2.079) P(9) = 500·8 = 4000 bacterias

Verificación lógica: en 9h se duplica 3 veces → 500→1000→2000→4000 ✓

Respuesta
P(9) = 4000 bacterias
DIFÍCIL · APLICADO Enfriamiento de Newton con tiempo desconocido ▼
Un cuerpo muerto se encuentra a 27°C en un cuarto a 20°C. Una hora después mide 25°C. La temperatura normal del cuerpo era 37°C. ¿Hace cuánto murió?
Paso 1 — Ley de enfriamiento de Newton

La temperatura T cambia proporcional a la diferencia con el ambiente (20°C).

dT/dt = k(T - 20)
Paso 2 — Hacer sustitución u = T - 20
du/dt = ku → u = u₀·e^(kt) T - 20 = (T₀ - 20)·e^(kt)
Paso 3 — Punto de referencia t=0: T=27°C

Cuando se descubre el cuerpo (t=0 para nosotros), T=27.

T - 20 = 7·e^(kt)
Paso 4 — Encontrar k con T(1)=25
25 - 20 = 7·e^(k·1) 5 = 7·e^k → e^k = 5/7 → k = ln(5/7) ≈ -0.3365
Paso 5 — Encontrar cuándo T era 37°C (hora de muerte)

Necesitamos el tiempo t* antes de t=0 (negativo):

37 - 20 = 7·e^(-0.3365·t*) 17 = 7·e^(-0.3365·t*) e^(-0.3365·t*) = 17/7 -0.3365·t* = ln(17/7) ≈ 0.887 t* ≈ -2.63 horas
Respuesta
La persona murió aproximadamente 2.6 horas antes de ser encontrada

Ecuaciones Diferenciales Exactas

¿Cuándo una EDO es exacta?

Si tienes una EDO de la forma M dx + N dy = 0, es exacta si:

∂M/∂y = ∂N/∂x

Esto significa que M y N son derivadas parciales de una misma función F(x,y). La solución es encontrar esa función F.

Algoritmo

  1. Verifica que ∂M/∂y = ∂N/∂x
  2. Integra M respecto a x: F = ∫M dx + g(y)
  3. Deriva F respecto a y: ∂F/∂y = (algo) + g'(y)
  4. Iguala a N: (algo) + g'(y) = N → despeja g'(y)
  5. Integra para obtener g(y)
  6. La solución es F(x,y) = C
Piénsalo así: estás buscando una función F tal que dF = M dx + N dy. La solución es el conjunto de curvas donde F vale una constante.
Si ∂M/∂y ≠ ∂N/∂x, la ecuación NO es exacta. Puede intentarse un factor integrante especial, pero eso es más avanzado.
FÁCIL Ecuación exacta directa ▼
(2x + y) dx + (x + 2y) dy = 0
Paso 1 — Verificar exactitud
M = 2x + y → ∂M/∂y = 1 N = x + 2y → ∂N/∂x = 1

Son iguales → ✓ Es exacta

Paso 2 — Integrar M respecto a x
F = ∫(2x + y) dx = x² + xy + g(y)
Paso 3 — Derivar F respecto a y e igualar a N
∂F/∂y = x + g'(y) = N = x + 2y g'(y) = 2y → g(y) = y²
Solución
x² + xy + y² = C
DIFÍCIL Exacta con funciones trigonométricas ▼
(e^x sin y - 2y sin x) dx + (e^x cos y + 2 cos x) dy = 0
Paso 1 — Verificar exactitud
M = e^x sin y - 2y sin x ∂M/∂y = e^x cos y - 2 sin x N = e^x cos y + 2 cos x ∂N/∂x = e^x cos y - 2 sin x ✓ Es exacta
Paso 2 — Integrar M respecto a x
F = ∫(e^x sin y - 2y sin x) dx F = e^x sin y + 2y cos x + g(y)
Paso 3 — Derivar F respecto a y e igualar a N
∂F/∂y = e^x cos y + 2 cos x + g'(y) = N e^x cos y + 2 cos x + g'(y) = e^x cos y + 2 cos x g'(y) = 0 → g(y) = 0
Solución
e^x sin y + 2y cos x = C

Crecimiento Poblacional II — Modelo Logístico

El problema del modelo exponencial

El modelo dP/dt = kP dice que la población crece infinitamente, lo cual no es real. En la naturaleza existe una capacidad de carga M (el máximo que el ambiente puede sostener).

Modelo logístico

dP/dt = kP(1 - P/M)

Cuando P es pequeña, (1 - P/M) ≈ 1, así que crece casi exponencial. Cuando P se acerca a M, el factor se hace casi 0 y el crecimiento se frena. Si P > M, ¡la población baja!

Solución

Se resuelve por fracciones parciales. El resultado es:

P(t) = M / (1 + A·e^(-kt))
donde A = (M - P₀) / P₀
Comportamiento: P siempre se acerca a M sin sobrepasarlo (si empezó por debajo). La curva tiene forma de S (sigmoide).
FÁCIL · APLICADO Población con límite ambiental ▼
Una isla puede sostener máximo 1000 conejos. Inicialmente hay 100. La tasa es k=0.5 /año. ¿Cuántos hay en 2 años?
Paso 1 — Datos
M = 1000, P₀ = 100, k = 0.5
Paso 2 — Calcular A
A = (1000 - 100)/100 = 900/100 = 9
Paso 3 — Aplicar fórmula en t=2
P(2) = 1000 / (1 + 9·e^(-0.5·2)) P(2) = 1000 / (1 + 9·e^(-1)) P(2) = 1000 / (1 + 9·0.3679) P(2) = 1000 / (1 + 3.311) = 1000/4.311 ≈ 232
Respuesta
P(2) ≈ 232 conejos
DIFÍCIL · APLICADO Encontrar k con datos de dos tiempos ▼
Un lago tiene capacidad para 500 peces. Al año 0 hay 50, al año 3 hay 200. Encuentra k y predice cuántos hay al año 10.
Paso 1 — Calcular A
A = (500 - 50)/50 = 450/50 = 9
Paso 2 — Usar P(3)=200 para encontrar k
200 = 500 / (1 + 9·e^(-3k)) 1 + 9e^(-3k) = 500/200 = 2.5 9e^(-3k) = 1.5 → e^(-3k) = 1/6 -3k = ln(1/6) = -ln 6 → k = ln(6)/3 ≈ 0.5973
Paso 3 — Predecir P(10)
P(10) = 500 / (1 + 9·e^(-0.5973·10)) e^(-5.973) ≈ 0.00254 P(10) = 500 / (1 + 9·0.00254) = 500/1.0229 ≈ 489
Respuesta
k ≈ 0.597/año | P(10) ≈ 489 peces

Problemas de Mezclas

El concepto

Tienes un tanque con una solución. Entra líquido, sale líquido. Quieres saber cuánta cantidad de alguna sustancia (sal, químico, etc.) hay en el tanque en cada momento.

Ley fundamental de mezclas dQ/dt = (tasa de entrada) - (tasa de salida)
Expandiendo dQ/dt = (concentración_entrada × flujo_entrada) - (Q/V_actual × flujo_salida)

Caso especial: flujos iguales

Si el flujo que entra = flujo que sale, el volumen V permanece constante. Eso simplifica mucho.

Si los flujos son distintos, V cambia con el tiempo: V(t) = V₀ + (flujo_entrada - flujo_salida)·t

Q siempre representa la CANTIDAD total (no la concentración). La concentración en cada momento es Q/V.
FÁCIL · APLICADO Tanque con flujos iguales ▼
Un tanque tiene 100 L con 10 kg de sal. Entra agua con 0.3 kg/L a 5 L/min y sale a la misma tasa. ¿Cuánta sal hay en t minutos?
Paso 1 — Plantear la EDO

Volumen constante = 100 L. Q(t) = kg de sal.

dQ/dt = 0.3 × 5 - (Q/100) × 5 dQ/dt = 1.5 - Q/20
Paso 2 — Forma estándar (lineal de 1er orden)
dQ/dt + Q/20 = 1.5

P = 1/20, Q_func = 1.5. Factor integrante: μ = e^(t/20)

Paso 3 — Resolver
(e^(t/20) Q)' = 1.5·e^(t/20) e^(t/20) Q = 30·e^(t/20) + C Q = 30 + Ce^(-t/20)
Paso 4 — Condición inicial Q(0)=10
10 = 30 + C → C = -20
Solución
Q(t) = 30 - 20e^(-t/20) kg
DIFÍCIL · APLICADO Tanque con volumen variable ▼
Tanque con 200 L y 5 kg de sal. Entra solución 0.02 kg/L a 3 L/min, sale a 1 L/min. ¿Cuánta sal hay en t=50 min?
Paso 1 — Volumen variable

Entra 3 L/min, sale 1 L/min → el volumen crece 2 L/min.

V(t) = 200 + 2t
Paso 2 — Plantear la EDO
dQ/dt = 0.02 × 3 - Q/(200+2t) × 1 dQ/dt = 0.06 - Q/(200+2t) dQ/dt + Q/(200+2t) = 0.06
Paso 3 — Factor integrante
P(t) = 1/(200+2t) ∫P dt = ∫1/(200+2t) dt = (1/2)ln(200+2t) μ = e^((1/2)ln(200+2t)) = √(200+2t)
Paso 4 — Multiplicar y resolver
(Q·√(200+2t))' = 0.06·√(200+2t) Q·√(200+2t) = ∫0.06·(200+2t)^(1/2) dt = 0.06 · (1/3)(200+2t)^(3/2) + C = 0.02(200+2t)^(3/2) + C Q = 0.02(200+2t) + C/(200+2t)^(1/2)
Paso 5 — Condición Q(0)=5
5 = 0.02(200) + C/√200 = 4 + C/14.14 C = (5-4)·14.14 = 14.14
Paso 6 — Evaluar Q(50)
Q(50) = 0.02(300) + 14.14/√300 Q(50) = 6 + 14.14/17.32 ≈ 6 + 0.816 ≈ 6.82 kg
Respuesta
Q(50) ≈ 6.82 kg de sal

Ecuaciones Homogéneas

¿Cuándo es homogénea?

Una EDO M dx + N dy = 0 es homogénea si M y N son funciones homogéneas del mismo grado. Una función es homogénea de grado n si:

f(tx, ty) = tⁿ · f(x, y)

En la práctica: si puedes escribir la EDO como dy/dx = f(y/x), entonces es homogénea.

Método de sustitución

La clave es hacer la sustitución y = vx, donde v es una nueva función de x.

y = vx → dy = v dx + x dv

Al sustituir, la ecuación se vuelve separable (en v y x). Luego integras y vuelves a y al final.

  1. Verifica que la EDO es homogénea
  2. Sustituye y = vx, dy = v dx + x dv
  3. Simplifica (x debería cancelarse, quedando solo v y x)
  4. Separa variables en v y x
  5. Integra
  6. Devuelve v = y/x
FÁCIL Homogénea de grado 1 ▼
Resolver: (x - y) dx + x dy = 0
Paso 1 — Verificar homogeneidad

M = x - y (grado 1), N = x (grado 1) → homogénea de grado 1 ✓

Paso 2 — Sustituir y = vx
dy = v dx + x dv (x - vx)dx + x(v dx + x dv) = 0 x(1-v)dx + vx dx + x² dv = 0 x dx - vx dx + vx dx + x² dv = 0 x dx + x² dv = 0
Paso 3 — Separar variables
dx/x + dv = 0
Paso 4 — Integrar
ln|x| + v = C v = C - ln|x|
Paso 5 — Volver a y (v = y/x)
y/x = C - ln|x|
Solución general
y = x(C - ln|x|)
DIFÍCIL Homogénea con integración compleja ▼
Resolver: (x² + y²) dx - 2xy dy = 0
Paso 1 — Verificar homogeneidad

M = x² + y² (grado 2), N = -2xy (grado 2) → homogénea ✓

Paso 2 — Sustituir y = vx
(x² + v²x²)dx - 2x(vx)(v dx + x dv) = 0 x²(1+v²)dx - 2vx²(v dx + x dv) = 0
Paso 3 — Dividir por x² y expandir
(1+v²)dx - 2v(v dx + x dv) = 0 (1+v²)dx - 2v² dx - 2vx dv = 0 (1 - v²)dx = 2vx dv
Paso 4 — Separar variables
dx/x = 2v/(1-v²) dv
Paso 5 — Integrar (fracciones parciales en la derecha)

La integral de 2v/(1-v²) dv: sea u = 1-v², du = -2v dv

∫2v/(1-v²) dv = -∫du/u = -ln|1-v²| ln|x| = -ln|1-v²| + C ln|x| + ln|1-v²| = C ln|x(1-v²)| = C → x(1-v²) = K
Paso 6 — Sustituir v = y/x
x(1 - y²/x²) = K x - y²/x = K
Solución general
x² - y² = Kx

Ecuaciones de Segundo Orden

Forma general (coeficientes constantes)

ay'' + by' + cy = f(x)

Si f(x) = 0 → se llama homogénea. Si f(x) ≠ 0 → no homogénea.

Paso 1 — Resolver la parte homogénea

Propones y = e^(rx) y buscas los valores de r. Eso te da la ecuación característica:

ar² + br + c = 0

Hay 3 casos según el discriminante Δ = b² - 4ac:

  • Δ > 0: dos raíces reales distintas r₁, r₂ → y_h = C₁e^(r₁x) + C₂e^(r₂x)
  • Δ = 0: raíz repetida r → y_h = (C₁ + C₂x)e^(rx)
  • Δ < 0: raíces complejas α ± βi → y_h = e^(αx)(C₁cos βx + C₂sin βx)

Paso 2 — Si es no homogénea: encontrar y_p

La solución completa es y = y_h + y_p. Para encontrar y_p se usa coeficientes indeterminados:

  • f(x) = eᵃˣ → propón y_p = Aeᵃˣ
  • f(x) = polinomio de grado n → propón y_p = polinomio de grado n
  • f(x) = sin/cos → propón y_p = A cos + B sin
  • Si la propuesta ya está en y_h, multiplica por x
La ecuación característica convierte un problema de ecuaciones diferenciales en un problema de álgebra. Es el truco más poderoso de las EDOs de 2do orden.
FÁCIL Raíces complejas (homogénea) ▼
Resolver: y'' + 4y' + 5y = 0
Paso 1 — Ecuación característica
r² + 4r + 5 = 0 r = (-4 ± √(16-20))/2 = (-4 ± √(-4))/2 r = (-4 ± 2i)/2 = -2 ± i
Paso 2 — Identificar α y β

α = -2 (parte real), β = 1 (parte imaginaria)

Paso 3 — Escribir solución
y = e^(-2x)(C₁ cos x + C₂ sin x)
Solución general
y = e^(-2x)(C₁ cos x + C₂ sin x)
DIFÍCIL No homogénea con condiciones iniciales ▼
Resolver: y'' - 3y' + 2y = e^(3x), y(0)=0, y'(0)=1
Paso 1 — Resolver parte homogénea
r² - 3r + 2 = 0 → (r-1)(r-2) = 0 r₁ = 1, r₂ = 2 (raíces reales distintas) y_h = C₁e^x + C₂e^(2x)
Paso 2 — Proponer y_p para e^(3x)

f(x) = e^(3x). Como r=3 no es raíz característica, propón:

y_p = Ae^(3x)
Paso 3 — Sustituir y_p en la EDO
y_p' = 3Ae^(3x), y_p'' = 9Ae^(3x) 9Ae^(3x) - 9Ae^(3x) + 2Ae^(3x) = e^(3x) 2Ae^(3x) = e^(3x) → A = 1/2 y_p = (1/2)e^(3x)
Paso 4 — Solución general
